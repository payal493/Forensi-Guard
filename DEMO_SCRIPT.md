## Setup (Before Recording)

1. **Start the server:**
   ```bash
   python app.py
   ```

2. **Open browser:**
   - Navigate to: `http://127.0.0.1:5000`
   - Use full screen mode (F11)
   - Clear browser cache if needed

3. **Test once:**
   - Click "Run Demo Analysis"
   - Verify results load correctly

## Questions to Anticipate

**Q: Is this using real AI models?**
> A: Currently using rule-based logic as a proof-of-concept. The architecture is designed to integrate with local LLMs like Llama 2 or Mistral for production deployment.

**Q: How does it preserve evidence integrity?**
> A: The AI layer operates in read-only mode. It never modifies original forensic artefacts. All interpretations are stored separately and clearly marked as AI-generated.

**Q: What about false positives?**
> A: The system provides confidence scores for all interpretations and includes alternative explanations where applicable. It's designed to assist human investigators, not replace them.

**Q: Can it handle real forensic data?**
> A: Yes, the system is designed to process standard forensic JSON output. The demo uses realistic test data, but the architecture supports integration with actual forensic tools.

**Q: What about privacy and security?**
> A: All processing happens locally. No data is sent to external APIs. The system is designed for on-premise deployment in secure environments.
