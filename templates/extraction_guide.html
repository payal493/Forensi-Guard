Step-by-Step Instructions

1 Enable Developer Mode

What to do:

  1. Open Settings on your Android phone
  2. Scroll down and tap About Phone
  3. Find Build Number
  4. Tap Build Number 7 times quickly
  5. You'll see a message: "You are now a developer!"

Why: This unlocks developer options needed for data extraction.

2 Enable USB Debugging

What to do:

  1. Go back to Settings
  2. Find and tap Developer Options (now visible)
  3. Scroll down to find USB Debugging
  4. Toggle USB Debugging ON
  5. Confirm when prompted

Why: This allows your computer to communicate with your phone safely.

3 Install Android Platform Tools

What to do:

  1. Download Android Platform Tools from the official Google website:
    2. Download Platform Tools
  2. Extract the downloaded ZIP file to a folder (e.g., Desktop)
  3. Open the extracted platform-tools folder

For Windows: Hold Shift + Right-click inside the folder → Select "Open PowerShell window here" or "Open command window here"

For Mac/Linux: Open Terminal and navigate to the folder using: cd /path/to/platform-tools

4 Connect Phone to Computer

What to do:

  1. Connect your Android phone to computer using USB cable
  2. On your phone, you'll see a popup: "Allow USB debugging?"
  3. Check "Always allow from this computer"
  4. Tap OK

Why: This establishes a secure connection between your phone and computer.

5 Verify Device Connection

What to do:

In the command window/terminal, type this command:

adb devices

Expected output:

List of devices attached
ABC123XYZ device

If you see your device ID followed by "device", you're connected! ✓

Troubleshooting: If no device appears, check USB cable, try different USB port, or restart phone.

6 Extract Basic Read-Only Data

Important: These commands only READ data. They do NOT modify anything on your phone.

Extract Installed Apps List ▼

This extracts a list of all installed apps on your phone:

adb shell pm list packages > apps.txt

Output file: apps.txt (saved in platform-tools folder)

Extract App Permissions ▼

This extracts information about app permissions:

adb shell dumpsys package > permissions.txt

Output file: permissions.txt

Extract Call Logs ▼

This extracts your call history (read-only):

adb shell content query --uri content://call_log/calls > calls.txt

Output file: calls.txt

Extract SMS Logs ▼

This extracts your SMS messages (read-only):

adb shell content query --uri content://sms > sms.txt

Output file: sms.txt

Where are the files? All extracted files are saved in your platform-tools folder.

Frequently Asked Questions

Q: Will this void my phone warranty?
A: No. Enabling USB debugging and using ADB does not void your warranty. We're not rooting or modifying your phone.
Q: My device is not detected. What should I do?
A: Try these steps: 1) Use a different USB cable, 2) Try a different USB port, 3) Restart your phone, 4) Reinstall USB drivers, 5) Make sure USB debugging is enabled.
Q: Is this safe for my phone?
A: Yes, completely safe. We're only reading data, not writing or modifying anything. It's like taking a photo of your data.
Q: Do I need to root my phone?
A: No! Rooting is NOT required. These commands work on any Android phone with USB debugging enabled.
Q: What if I get "permission denied" errors?
A: Some data may require additional permissions. This is normal. The tool will extract what's accessible without root access.
Q: Can I turn off USB debugging after extraction?
A: Yes! Once you're done, you can disable USB debugging in Developer Options for security.
